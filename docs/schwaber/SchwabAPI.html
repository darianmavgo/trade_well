Charles Schwab API Reference

Comprehensive OpenAPI 3.0 specifications for Charles Schwab Developer APIs, covering Account Access, Positions, Real-time Order Routing, Transactions, and Market Data feeds.

OAuth 2.0 Auth Server https://api.schwabapi.com/v1/oauth
Trader API (Accounts & Orders) https://api.schwabapi.com/trader/v1
Market Data API https://api.schwabapi.com/marketdata/v1

1. OAuth 2.0 Authentication

POST https://api.schwabapi.com/v1/oauth/token Exchange Code or Refresh Token

Exchanges an authorization code for bearer tokens, or refreshes an expired access token using a refresh token. Requires HTTP Basic Authentication with client_id:client_secret.

Request Headers
HeaderTypeDescription
Authorizationstring REQUIREDBasic base64(client_id:client_secret)
Content-Typestring REQUIREDapplication/x-www-form-urlencoded
Form Parameters
ParameterTypeDescription
grant_typestring REQUIREDauthorization_code or refresh_token
codestringThe authorization code received at your callback URL (valid for 30 seconds).
redirect_uristringMust exactly match your registered app callback URL.
refresh_tokenstringRequired when grant_type is refresh_token.
Response Payload (200 OK)
JSON Response
{
  "access_token": "I0.b2F1dGgyLmNkYy5zY2h3YWIuY29t...",
  "refresh_token": "Dkdn15WYVIerHkKjogS9calRcGAeZPCb...",
  "token_type": "Bearer",
  "expires_in": 1800,
  "scope": "api",
  "id_token": "eyJ0eXAiOiJKV1QiLCJhbGciOi..."
}
GET https://api.schwabapi.com/v1/oauth/authorize User Consent & Login Flow

Launches the Schwab customer login and consent portal. The user logs in with their personal brokerage credentials and selects accounts to grant permissions to.

Query Parameters
ParameterTypeDescription
client_idstring REQUIREDYour Schwab Developer App Key
redirect_uristring REQUIREDRegistered App Callback URL

GET /accounts/{accountNumber}/orders Get All Orders for Specific Account

Returns orders placed within a date range for a specific account. Supports filtering by status (WORKING, FILLED, CANCELED, REJECTED).

Query Parameters
ParameterTypeDescription
fromEnteredTimestring (ISO-8601)Start date (e.g. 2026-09-01T00:00:00.000Z)
toEnteredTimestring (ISO-8601)End date (e.g. 2026-09-03T23:59:59.000Z)
maxResultsintegerMaximum number of orders returned (default: 3000)
statusstringFilter: AWAITING_PARENT_ORDER, FILLED, WORKING, CANCELED, REJECTED
DEL /accounts/{accountNumber}/orders/{orderId} Cancel Open Order

Cancels an existing working or pending order. Returns HTTP 200 OK or 204 No Content upon receipt of the cancellation request.

PUT /accounts/{accountNumber}/orders/{orderId} Replace / Cancel-Replace Order

Modifies an existing order (price, quantity, duration) via atomic Cancel/Replace.

POST /accounts/{accountNumber}/previewOrder Preview Order Before Placement

Validates an order payload against buying power, commission costs, and order validation rules without placing it on the exchange.

4. Transactions History API

GET /accounts/{accountNumber}/transactions Query Account Transaction History

Lists completed transactions including trade executions, dividend payments, deposits, withdrawals, and fee adjustments.

Query Parameters
ParameterTypeDescription
startDatestring (ISO-8601) REQUIREDStart timestamp (e.g. 2026-08-01T00:00:00.000Z)
endDatestring (ISO-8601) REQUIREDEnd timestamp (e.g. 2026-09-01T23:59:59.000Z)
typesstringTransaction type: TRADE, RECEIVE_AND_DELIVER, DIVIDEND_OR_INTEREST, ACH_RECEIPT, ACH_DISBURSEMENT, ELECTRONIC_FUND

5. User Preferences & Streamer API

GET /userPreference Get User Preferences & Streamer Socket Info

Returns user configuration, default account settings, and WebSocket streaming connection credentials (streamerSocketUrl, schwabClientCorrelId, schwabClientChannel).

6. Market Data API (Market Data Production)

GET https://api.schwabapi.com/marketdata/v1/quotes Batch Real-Time Quotes

Fetches real-time market quotes and depth for multiple symbols across Equities, Options, Mutual Funds, and Indices.

Query Parameters
ParameterTypeDescription
symbolsstring REQUIREDComma-separated symbols (e.g. AAPL,MSFT,SOFI,SPY)
fieldsstringOptional fields to return: quote, fundamental, extended, reference, regular
indicativebooleanInclude indicative quotes (default: false)
GET https://api.schwabapi.com/marketdata/v1/chains Option Chains Matrix

Fetches full Option Chains for a specified equity or index ticker with greeks, strikes, expiration dates, open interest, and implied volatility.

Query Parameters
ParameterTypeDescription
symbolstring REQUIREDUnderlying equity or index ticker (e.g. SPY, AAPL)
contractTypestringCALL, PUT, or ALL (default: ALL)
strikeCountintegerTotal number of strikes above and below the at-the-money price
includeUnderlyingQuotebooleanInclude current market price and quote of underlying stock
strategystringSINGLE, ANALYTICAL, COVERED, VERTICAL, CALENDAR, STRANGLE, STRADDLE, BUTTERFLY, CONDOR, IRON_CONDOR
rangestringITM (In-The-Money), NTM (Near-The-Money), OTM (Out-of-The-Money), ATM (At-The-Money)
fromDatestring (YYYY-MM-DD)Filter expirations on or after this date
toDatestring (YYYY-MM-DD)Filter expirations on or before this date
GET https://api.schwabapi.com/marketdata/v1/pricehistory Historical OHLCV Candlestick Data

Fetches historical open, high, low, close, and volume candles for technical analysis and backtesting.

Query Parameters
ParameterTypeDescription
symbolstring REQUIREDTicker symbol (e.g. NVDA)
periodTypestringday, month, year, ytd
frequencyTypestringminute, daily, weekly, monthly
frequencyintegerFrequency multiplier (e.g. 1, 5, 15, 30 for minute)
needExtendedHoursDatabooleanInclude pre-market and after-hours data (default: false)
GET https://api.schwabapi.com/marketdata/v1/movers/{index} Top Market Movers / Screeners

Returns the top gainers, losers, and most active volume equities for major indexes ($DJI, $COMPX, $SPX).

GET https://api.schwabapi.com/marketdata/v1/markets Market Operating Hours & Holidays

Retrieves trading session schedules, holiday closures, and pre/post-market operational windows for equity, option, and bond exchanges.
